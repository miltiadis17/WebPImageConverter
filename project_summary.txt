КОМАНДЫ:
--------
Компиляция:       mvn clean compile
Запуск:           mvn javafx:run
Тесты:            mvn test
Сборка JAR:       mvn clean package
Запуск JAR:       java -jar target/webp-converter-1.0-SNAPSHOT.jar

ИЗВЕСТНЫЕ ПРОБЛЕМЫ:
-------------------
⚠ WebP ImageIO 0.1.6 не поддерживает Apple Silicon (ARM64)
  Решение: использовать Rosetta 2 или x86_64 Java для тестов
  Примечание: приложение работает корректно, проблема только в тестах
