# WebP Image Converter

JavaFX приложение для конвертации изображений в формат WebP.

## Описание

Это десктопное приложение позволяет конвертировать изображения различных форматов (JPG, PNG, BMP, GIF) в формат WebP с настраиваемым качеством сжатия.

## Возможности

- Графический интерфейс на JavaFX
- Выбор папки с изображениями через файловый диалог
- Два режима работы:
  - Обработка только файлов в корневой папке
  - Рекурсивная обработка всех вложенных папок
- Настройка качества сжатия (1-100)
- Прогресс-бар для отслеживания процесса конвертации
- Детальный отчет о результатах конвертации
- Автоматическое создание выходной папки с суффиксом "Webp"

## Принцип работы

1. Выберите папку с изображениями (например, `files/frames`)
2. Настройте параметры конвертации:
   - Включите/выключите рекурсивную обработку
   - Установите желаемое качество сжатия
3. Нажмите кнопку "Конвертировать"
4. Результат будет сохранен в новую папку с суффиксом "Webp" (например, `files/framesWebp`)

## Требования

- Java 17 или выше
- Maven 3.6+

## Сборка и запуск

### Компиляция проекта

```bash
mvn clean compile
```

### Запуск приложения

```bash
mvn javafx:run
```

### Создание исполняемого JAR

```bash
mvn clean package
```

После сборки JAR файл будет находиться в `target/webp-converter-1.0-SNAPSHOT.jar`

Для запуска JAR:

```bash
java -jar target/webp-converter-1.0-SNAPSHOT.jar
```

## Поддерживаемые форматы

**Входные форматы:**
- JPG/JPEG
- PNG
- BMP
- GIF

**Выходной формат:**
- WebP

## Пример использования

Если в папке `files/frames` находятся файлы:
- `frame_1.jpg`
- `frame_2.png`
- `frame_3.png`

После конвертации будет создана папка `files/framesWebp` с файлами:
- `frame_1.webp`
- `frame_2.webp`
- `frame_3.webp`

При включенной рекурсивной обработке структура вложенных папок будет сохранена.

## Тестирование

Проект включает комплексный набор тестов:

### Запуск тестов

```bash
mvn test
```

### Типы тестов

1. **Unit-тесты** (`ImageConverterServiceTest.java`):
   - Конвертация одиночного изображения
   - Конвертация множества файлов разных форматов
   - Рекурсивная и нерекурсивная обработка
   - Игнорирование не-изображений
   - Отслеживание прогресса
   - Обработка ошибок
   - Граничные значения качества
   - Сохранение размеров изображения
   - Специальные символы в именах файлов

2. **Интеграционные тесты** (`WebPConverterIntegrationTest.java`):
   - Конвертация полной структуры проекта
   - Смешанный контент (изображения + другие файлы)
   - Массовая конвертация (50+ файлов)
   - Разные уровни качества
   - Пустые подпапки
   - Сохранение качества и цветов
   - Все поддерживаемые форматы
   - Большие изображения (2000x1500)

### Вспомогательные классы

### Поддержка Apple Silicon

**✅ ОБНОВЛЕНО:** Приложение теперь полностью поддерживает Apple Silicon (M1/M2/M3)!

Мы перешли с библиотеки `webp-imageio` на `Scrimage 4.1.1`, которая имеет нативную поддержку ARM64 архитектуры. Приложение работает на всех платформах без необходимости Rosetta 2.
